# 🎮 Jogo do Número Secreto

Este é um jogo simples de adivinhação de números desenvolvido com HTML, CSS e JavaScript, como parte dos estudos de lógica de programação.

## 🚀 Sobre o Projeto

O objetivo do jogo é que o usuário adivinhe um número secreto gerado aleatoriamente entre 1 e 10. A cada tentativa, o jogo informa se o número secreto é maior ou menor que o palpite do usuário. Ao acertar, uma mensagem de sucesso é exibida, juntamente com o número de tentativas.

## 🕹️ Como Jogar

1.  Clone ou baixe este repositório.
2.  Abra o arquivo `index.html` em seu navegador de preferência.
3.  Uma caixa de diálogo (`prompt`) solicitará que você insira um número de 1 a 10.
4.  Siga as dicas ("O número secreto é maior" ou "O número secreto é menor") para adivinhar o número.
5.  Quando você acertar, uma mensagem de parabéns será exibida na tela!

## ✨ Funcionalidades

- Geração de um número aleatório a cada novo jogo.
- Interação com o usuário através de `prompt` e `alert`.
- Validação do palpite do usuário, com dicas para o próximo palpite.
- Contagem do número de tentativas.
- Mensagem de sucesso personalizada ao final do jogo.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
